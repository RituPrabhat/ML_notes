# 📌 Outliers in Data Analysis

## What is an Outlier?

An **outlier** is a data point that **deviates significantly** from the rest of the observations in a dataset, to the point of arousing suspicion that it was generated by a different mechanism than the rest of the data.

It has two important aspects:

- **Statistically far from the rest** *(the measurable part)*
- **Possibly generated by a different process** *(the interpretive part)*

---

# Is an Outlier Always Bad Data?

**No.**

An outlier is **not always an error**. Sometimes an outlier is actually **the most important data point** in your dataset.

For example:

- Fraudulent bank transactions
- System failures
- Rare diseases
- High-value customers
- Cyber attacks

Deleting these values blindly can be **worse than keeping them**, because they may contain the exact information you are trying to discover.

---

# Common Causes of Outliers

| Cause | Example | What to Do |
|--------|---------|------------|
| **Data entry error** | Age entered as **200** instead of **20** | Fix or remove |
| **Measurement / instrument error** | Sensor glitch reads temperature as **-999** | Remove or treat as missing |
| **Natural variation (genuine rare event)** | A billionaire's income in a salary dataset | Usually keep, maybe transform |
| **Sampling error** | Accidentally including a wrong population (e.g., a test account mixed into real user data) | Remove |
| **Novelty / the actual signal you care about** | Fraudulent transactions, network intrusions | Keep — this IS what you're trying to detect |

# Types of Outliers

## 1. Global (Point) Outliers

A **single data point** that lies far away from all other observations when compared against the **entire dataset**.

### Example

Suppose most salaries are between:

- ₹5 lakh
- ₹10 lakh

One salary is:

- ₹5 crore

That single salary is a **global outlier**.

---

## 2. Contextual (Conditional) Outliers

A value that looks **normal overall**, but becomes **abnormal in a specific context**.

The context could be:

- Time
- Season
- Location
- Age group
- Department
- Customer type

### Example

A temperature of **35°C**:

- ✅ Normal during summer
- ❌ Huge outlier during winter

The value itself isn't strange—the **context changes what is considered normal**.

---

## 3. Collective Outliers

A **group of observations** that individually appear normal, but **together form an abnormal pattern**.

### Example

Suppose a web server receives:

```
100 requests
102 requests
98 requests
101 requests
99 requests
```

Everything looks normal.

Suddenly:

```
450
470
490
510
530
```

Each request count may not seem impossible individually, but the **continuous spike together** indicates an anomaly such as:

- DDoS attack
- Bot traffic
- System malfunction

This is called a **collective outlier**.

---

# Which Outliers Do Beginner Techniques Detect?

Most beginner-level outlier detection techniques only detect:

- ✅ Global (Point) Outliers

Examples include:

- **IQR Method**
- **Z-Score Method**

These methods generally **cannot detect**:

- ❌ Contextual outliers
- ❌ Collective outliers

Detecting contextual or collective outliers usually requires:

- Grouping data by context
- Time-series analysis
- Sequence-aware methods
- Machine Learning / Anomaly Detection algorithms
